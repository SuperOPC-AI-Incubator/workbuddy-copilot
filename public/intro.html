SuperBrain Copilot

工业自动化 AI 导师观察台

为「SuperBrain AI 孵化器」定制的 PLC 学习辅导系统：学员在 WorkBuddy 中提问，AI 自动同步到导师端，导师可实时介入、批注、辅导。

🔗 WorkBuddy 联动 ⚡ Supabase Realtime 🤖 Deepseek AI 🔐 RLS 角色权限

核心效果

🧑‍🏫

双角色工作区

学员端专注提问与查看 AI 回复；导师端一览全班学生、会话列表、实时事件流，并可直接回复学员。

📡

WorkBuddy 自动同步

学员在 WorkBuddy 里的每轮对话（prompt + reply + AI 诊断）自动 POST 到云端，无需学员手动操作。

🔔

导师实时提醒

学员点击「🆘 呼叫导师」或触发 error 级诊断时，导师端会播放提示音、闪烁标签页、弹出浏览器通知。

🤖

AI 先答、导师后介入

Deepseek 先给出 PLC 领域回复，并自动判断学员是否卡壳；导师随后可一键 AI 润色或直接回复。

🛡️

严格数据隔离

基于 Supabase RLS + 独立 user_roles 表：学员只能读写自己的 timeline_items，导师可查看全部学员。

⏰

漏传检测

导师端自动标记「最近 24 小时无同步」的学员，方便发现 AI 漏传或 WorkBuddy 未生效的情况。

学员使用流程

学员只需一次配置，之后所有对话自动同步。

登录 SuperBrain
→
进入 /workbuddy 复制 SKILL.md
→
在 WorkBuddy 新建 Skill
→
正常对话，自动上传

SKILL.md 中写死「每次回复后必须调用 curl 同步」，并绑定学员专属 Bearer Token，无需 OAuth。

导师工作区效果

左侧：学员列表

显示每位学员最近一次活跃时间、最近 24 小时是否同步、当前最高 severity 等级。 stale 学员会显示 漏传 标签。

中间：会话时间线

选中学员后展示其全部会话；每条 timeline_item 标注来源（Web / WorkBuddy）、类型（prompt / reply / diagnosis / mentor）、severity。

右侧：回复与 AI 辅助

导师可直接输入回复；点击「AI 润色」按钮由 Deepseek 生成专业 mentor 回复草稿。

🛠️

同时保留标准 MCP 端点（/mcp）和更稳定的 SKILL.md + HTTP 同步方案。

安全设计

我们从未把角色写进 users 表，而是使用独立的 public.user_roles 表 + private.has_role() 安全定义函数，避免 RLS 递归和权限提升。

  • RLS INSERT： 学员只能写入 author_id = auth.uid() 的 timeline_items。
  • RLS SELECT： 学员只能读取自己的会话数据；导师可读取全部学员。
  • 服务端鉴权： WorkBuddy 同步使用 Bearer Token 或 HMAC 签名，不依赖客户端 localStorage。
